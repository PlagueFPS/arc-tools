# Website development

The website uses TanStack Start, React, TanStack Router file routes, React Query, Tailwind CSS, and shadcn/ui with Base UI. Keep page components and their utilities together. `src/styles.css` owns Tailwind theme tokens and global resets; component styling belongs in JSX utility classes. Add shadcn components from `apps/website` with its Base UI preset in `components.json`. Use the shared UI components for controls and cards. Navigation remains links styled with button variants. Fontsource Barlow is served locally and supplies sans, heading, and code fonts.

`src/router.tsx` creates a QueryClient per router and passes it through router context. The root route provides it to React Query. Enrollment status is private browser state: enable its query only after mount, decode the shared `@arctools/twitch/enrollment` contract with the workspace Effect version, and pass React Query's AbortSignal to fetch. Do not fetch session state in server loaders, prefetch it during SSG, or poll. Refresh is manual.

Website is public and owns both OAuth callback branches, browser enrollment HTTP, and the HttpOnly enrollment cookie. HTTPS uses the original Secure __Host- cookie; exact http://localhost:3000 uses a separate local cookie without Secure, and neither reads the other cookie. Native TanStack server routes call Bot through the typed BOT service binding with Alchemy toRpcAsync. Load cloudflare:workers lazily inside the handler. Bot owns account policy, provider secrets, and storage. Use type-only Bot resource imports in Website server code. Do not import server barrels into browser code. Enrollment uses `/oauth/twitch/enroll`; status uses `/oauth/twitch/enroll/status` with same-origin credentials and no-store caching.

TanStack Start prerenders `/` and `/connect` to public HTML. Connect prerenders a generic loading shell, then reads the browser session after hydration. Unknown routes use the root 404 component. `src/routeTree.gen.ts` is generated by TanStack Router; never edit it by hand.

Use the standard Tailwind, TanStack Start, and React Vite plugins. TanStack Start and Vite use their default root base path in development and production. No custom framework adapters or Vite plugins are needed. Alchemy uses Website.Vite's standard SSR entry and assets configured with `htmlHandling: "drop-trailing-slash"` and `notFoundHandling: "none"`.

`bun run --cwd apps/website dev` serves the standalone preview at http://localhost:3000. Without the binding, pages render and browser operations return private unavailable responses. Full enrollment uses the Bot service binding under Alchemy. Website dev/preview and Alchemy dev use strict port 3000 without an explicit host override. Nonproduction OAuth defaults to http://localhost:3000; production requires ARC_WEBSITE_URL matching the actual HTTPS Worker origin. ARC_BOT_URL remains the HTTPS webhook origin. Only Bot needs a local HTTPS tunnel. Leave existing live Bot and tunnel processes alone.

Use React Testing Library with happy-dom and a real QueryClient. Stub external HTTP responses, not framework modules. Cover rendered content, session states, refresh failures, and cancellation.

After code changes, run the repository root checks in order:

1. `bun run typecheck`
2. `bun run lint`
3. `bun run fmt`
4. `bun run test`
