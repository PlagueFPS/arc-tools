# Website development

The website uses TanStack Start, React, TanStack Router file routes, React Query, Tailwind CSS, and shadcn/ui with Base UI. Keep page components and their utilities together. `src/styles.css` owns Tailwind theme tokens and global resets; component styling belongs in JSX utility classes. Add shadcn components from `apps/website` with its Base UI preset in `components.json`. Use the shared UI components for controls and cards. Navigation remains links styled with button variants. Fontsource Barlow is served locally and supplies sans, heading, and code fonts.

`src/router.tsx` creates a QueryClient per router and passes it through router context. The root route provides it to React Query. Enrollment status is private browser state: enable its query only after mount, decode the shared `@arctools/twitch/enrollment` contract with the workspace Effect version, and pass React Query's AbortSignal to fetch. Do not fetch session state in server loaders, prefetch it during SSG, or poll. Refresh is manual.

Bot is the canonical public origin and owns OAuth and enrollment cookies. Website is a private asset worker with no Bot dependency. Do not import server barrels into browser code. Enrollment uses `/oauth/twitch/enroll`; status uses `/oauth/twitch/enroll/status` with same-origin credentials and no-store caching.

TanStack Start prerenders `/` and `/connect` to public HTML. Connect prerenders a generic loading shell, then reads the browser session after hydration. Unknown routes use the root 404 component. `src/routeTree.gen.ts` is generated by TanStack Router; never edit it by hand.

Use the standard Tailwind, TanStack Start, and React Vite plugins. TanStack Start and Vite use their default root base path in development and production. Bot forwards Vite module paths only during development. No custom framework adapters or Vite plugins are needed. Alchemy uses Website.Vite's standard SSR entry and assets configured with `htmlHandling: "drop-trailing-slash"` and `notFoundHandling: "none"`. Bot forwards page paths unchanged in development and production.

`bun run --cwd apps/website dev` serves the standalone preview at http://localhost:5180. Full enrollment requires the Bot origin and its HTTPS session cookie. Leave existing live Bot and tunnel processes alone.

Use React Testing Library with happy-dom and a real QueryClient. Stub external HTTP responses, not framework modules. Cover rendered content, session states, refresh failures, and cancellation.

After code changes, run the repository root checks in order:

1. `bun run typecheck`
2. `bun run lint`
3. `bun run fmt`
4. `bun run test`
